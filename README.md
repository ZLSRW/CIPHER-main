# Included model inputs

`strict/autdb` and `strict/sfari` contain the fixed **processed** inputs used by
CIPHER, including graph views, node covariates, supervision, and split files.
These are not complete raw database downloads. See `../docs/DATA.md` for the
schema, provenance, and data-use notice. `SHA256SUMS` uses paths relative to the
repository root and covers every included CSV and metadata JSON.
